# La Belle Table — Site vitrine (démo)

Site vitrine statique pour un restaurant fictif, généré comme test/tutoriel pour le workflow Claude → GitHub → Infomaniak.

## Structure
- `index.html` — contenu et structure de la page
- `style.css` — mise en page et design
- `script.js` — interactions (menu mobile, formulaire de contact démo)

## Aperçu local
Ouvrez simplement `index.html` dans un navigateur, ou lancez un petit serveur local :

```bash
python3 -m http.server 8000
```

puis rendez-vous sur `http://localhost:8000`.
